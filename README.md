# FitLog | Workout & Fitness Tracker

FitLog is a modern workout and fitness tracking web application built with Next.js. 
It helps users explore workouts, create a daily workout plan, save favorite workouts, 
and organize their fitness activities in one place.

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Icons
- React Tostify

## ✨ Key Features

1. **Workout Library**
   - Browse and explore different workout exercises.

2. **Today's Workout Plan**
   - Add workouts to your daily workout plan and manage them easily.

3. **Save Workouts**
   - Save favorite workouts for quick access later.

4. **Workout Sorting**
   - Sort workouts by duration, calories burned, or rating.

5. **Responsive Design**
   - Fully responsive interface that works across desktop, tablet, and mobile devices.
